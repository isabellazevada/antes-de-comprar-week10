# Abrir el proyecto localmente

La página publicada está en https://antes-de-comprar-isabella.isazevada.chatgpt.site

Desde la carpeta del proyecto ejecuta `python3 -m http.server 8000 --directory dist` y abre http://localhost:8000.

Para ejecutar las pruebas: `npm test` (requiere Node.js).

La IA y la lectura de imagen están simuladas y etiquetadas. No hay claves ni conexión bancaria ni base de datos. No se verifica ninguna política de una tienda real.

Este archivo ZIP importa el estado final de la fuente. No transfiere los commits originales a la historia de GitHub. La cronología original se enumera en SOURCE_HISTORY.md.
